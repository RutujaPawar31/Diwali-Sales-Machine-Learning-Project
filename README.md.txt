# Diwali Sales Prediction – Machine Learning Project

## Project Overview
This project uses Machine Learning to predict customer purchase amounts based on customer demographics and shopping-related information from Diwali sales data.

## Project Objective
To build and evaluate regression models that predict customer purchase amounts.

## Technologies Used
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Pickle

## Machine Learning Algorithms
1. Linear Regression
2. Decision Tree Regressor
3. Random Forest Regressor
4. Gradient Boosting Regressor

## Model Evaluation
The models were evaluated using:
- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
- R² Score

## Best Model
Linear Regression

- R² Score: 0.6385
- MAE: 2372.39

## Project Workflow
1. Data Loading
2. Data Cleaning
3. Exploratory Data Analysis
4. Feature Selection
5. Categorical Encoding
6. Train-Test Split
7. Model Training
8. Model Evaluation
9. Model Comparison
10. Model Saving
11. Purchase Amount Prediction

## Conclusion
Linear Regression achieved the best performance among the four tested models on the current test dataset, with an R² score of approximately 63.85%.

This project demonstrates the application of regression-based Machine Learning techniques to retail sales data.
